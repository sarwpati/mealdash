# 🍔 MealDash — Food Delivery Platform

MealDash is a food delivery web application inspired by modern food ordering platforms. This project is being developed as a learning project, with plans to improve its features, functionality, and user experience.

## 🌐 Links

- **GitHub Repository:** [MealDash](https://github.com/sarwpati/mealdash)
- **Live Demo:** Coming soon

## ✨ Features

- Food delivery landing page
- Restaurant discovery interface
- Search and location input UI
- Grocery and food category sections
- Restaurant listings and ratings
- Responsive layout (to be improved and tested)

## 🛠️ Tech Stack

- React
- JavaScript
- HTML5
- CSS3
- Redux Toolkit
- React Redux
- Parcel

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sarwpati/mealdash.git
```

### 2. Enter the project directory

```bash
cd mealdash
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open the local URL shown in your terminal, usually `http://localhost:1234`.
